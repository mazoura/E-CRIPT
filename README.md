# E-CRiPT — Ethical Rules CRUD Conference Prototype

A Flask conference-demo application centered on the paper's Ethical Consistency Rules.

## Included
- Create / Read / Update / Delete rules
- Activate / deactivate rules
- Trigger, conditions and reactions editor
- Rule selection and injection into a policy pipeline
- Policy testing against clinical prompts
- SHA-256 fingerprint for injected rule sets
- Professional responsive UI

## Run
pip install -r requirements.txt
python app.py

Then open http://127.0.0.1:5000
